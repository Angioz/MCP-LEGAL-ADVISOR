# Legal Knowledge MCP - Project Context

## Project Overview
**Legal Knowledge MCP Server** is a Model Context Protocol (MCP) server that provides AI systems (like Claude) with access to legal knowledge from 7 jurisdictions across Europe and beyond.

## Goals
1. Enable Claude to research EU, Italian, Greek, UK, French, German, and Spanish legislation
2. Provide 13 specialized legal data tools for accurate legal research
3. Support compliance, regulatory, and legal technology use cases
4. Build production-ready MCP integration for broader adoption

## Scope
- **Coverage**: 7 jurisdictions (EU, Italy, Greece, UK, France, Germany, Spain)
- **Tools**: 13 legal data sources (regulators, parliaments, legislation databases)
- **Users**: Legal professionals, compliance teams, legal tech companies, developers
- **Deployment**: npm package, GitHub public repository

## Target Launch Date
- **Original Target**: 2026-01-14 (Phase 1 complete)
- **Phase 2 Target**: Q1 2026 (LinkedIn launch)
